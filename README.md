# 무한문답

영어 단어, 수도, 상식 등 원하는 문답을 무작위로 반복 학습하는 GitHub Pages용 정적 웹앱입니다.

## 실행

별도 빌드 없이 `index.html`을 열거나 아래 명령으로 실행하세요.

```sh
python -m http.server 4173
```

브라우저에서 http://localhost:4173 으로 접속합니다.

## 사용

- 카테고리를 선택하고 답을 입력한 뒤 Enter로 제출합니다. 결과 확인 후 Enter를 다시 누르면 다음 문제가 나옵니다.
- 문제는 선택한 카테고리의 미암기 문제에서 매번 무작위로 추출합니다. 중복 출제됩니다.
- 문제 보관함에서 문제와 카테고리를 추가, 수정, 삭제합니다. 좌측 카테고리를 선택하면 해당 카테고리 수정·삭제 버튼이 표시됩니다.
- ‘암기 완료’를 누르면 출제에서 제외됩니다. 보관함에서 다시 눌러 학습 대상으로 되돌릴 수 있습니다.
- 정답은 대소문자와 앞뒤 공백을 무시합니다. 여러 정답은 `|`로 구분합니다.
- 데이터는 해당 브라우저의 localStorage에 저장됩니다. 기기·브라우저 간 자동 동기화는 없으므로 백업/불러오기를 사용하세요. 브라우저 데이터 삭제 시 기록도 삭제됩니다.

## GitHub Pages 배포

이 파일들을 GitHub 저장소의 기본 브랜치에 올린 후 Settings → Pages → Deploy from a branch → 기본 브랜치 / (root)를 선택하세요. 상대 경로를 사용하므로 프로젝트 하위 URL에서도 동작합니다. `.nojekyll`이 포함되어 있습니다.

나라와 수도 샘플 문제 1개(대한민국 → 서울)가 최초 실행 시 제공됩니다. 서버, API 키, 패키지 설치가 필요 없습니다. Google Fonts에 접근할 수 없는 환경에서는 시스템 글꼴을 사용합니다.
