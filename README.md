# ∞ 무한문답

영어 단어의 뜻이나 나라의 수도처럼 외우고 싶은 내용을 직접 문제로 만들고, 답을 입력하며 반복해서 공부하는 웹앱입니다.

**[▶ 무한문답에서 학습 시작하기](https://kookjd7759.github.io/infinite_QnA/)**

## 첫 문제 풀기

1. **반복 학습 → 외우기 → 나라와 수도**를 선택하세요. 처음에는 예시 문제 **대한민국 → 서울** 한 개가 들어 있습니다.
2. 답을 입력하고 <kbd>Enter</kbd>를 누르면 채점됩니다. 틀렸을 때는 정답이 함께 표시됩니다.
3. <kbd>Enter</kbd>를 다시 누르면 다음 카드가 나옵니다. 선택한 카테고리에서 현재 모드에 해당하는 문제를 무작위로 뽑으므로 같은 문제를 여러 번 만날 수 있습니다.

## 나만의 문제 만들기

**문제 보관함 → 카테고리 추가**로 주제를 만든 뒤, 그 카테고리를 열고 **문제 추가**를 누르세요. 여러 표현을 정답으로 인정하려면 답을 `|`로 구분하세요. 예를 들어 `고요한 | 평온한`을 등록하면 둘 중 하나만 입력해도 정답입니다. 채점할 때 영문 대소문자와 앞뒤 공백은 무시합니다.

| 보관함에서 하고 싶은 일 | 조작 |
| --- | --- |
| 문제나 답 수정 | 해당 행의 ✎를 누르고 내용을 고친 뒤 ✓로 저장 |
| 문제 하나 삭제 | 행의 🗑을 누르고 삭제 확인 |
| 외운 문제 제외 | **안 외움**을 눌러 **✓ 외움**으로 변경 |
| 다시 학습하기 | **✓ 외움**을 눌러 **안 외움**으로 변경 |
| 카테고리 전체 삭제 | 문제 목록 아래 **이 카테고리 삭제**를 누르고 포함된 문제 수를 확인한 뒤 삭제 |

## 외우기와 복습

**외우기**는 안 외운 문제만, **복습**은 외움으로 표시한 문제만 출제합니다. 학습 중에도 모드를 바꿀 수 있습니다.

## 오답 복습과 암기 기록

학습 화면에서 **오답만 연습**을 켜면 현재 모드와 카테고리에서 마지막으로 틀린 문제만 나옵니다. 다시 맞히면 오답 연습에서 빠지고, **외움**으로 표시할 때까지 일반 반복 학습에서는 계속 나옵니다. 카테고리 카드의 진행 막대는 전체 문제 중 직접 **외움**으로 표시한 비율입니다.

> **기기를 옮길 때** · 문제와 기록은 현재 브라우저에 저장됩니다. 보관함의 **데이터 백업**으로 JSON 파일을 내려받고, 다른 브라우저에서 **백업 불러오기**를 선택하세요. 불러오기를 확인하면 해당 브라우저의 데이터가 백업 내용으로 교체됩니다.

## 로컬 실행과 배포

로컬에서는 [index.html](./index.html)을 브라우저로 열면 됩니다. 로컬 서버로 실행하려면 프로젝트 폴더에서 다음 명령을 실행한 뒤 [localhost:4173](http://localhost:4173)에 접속하세요.

```sh
python -m http.server 4173
```

GitHub Pages에 배포할 때는 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택하고, 프로젝트 파일이 있는 브랜치와 **/(root)**를 지정하세요. 별도 빌드 단계는 없습니다.
